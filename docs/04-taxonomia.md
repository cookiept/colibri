# 04 · Taxonomia

Os temas são os **12 drivers do inquérito VoC da Colibri**, mais dois que só aparecem em reclamações. Usar os mesmos nomes permite pôr lado a lado o NPS de um driver e o número de queixas sobre ele. A lista em código está em `app/js/modelo/taxonomia.js`.

| Tema | Origem |
| --- | --- |
| Serviço/Atendimento | VoC |
| Zona de refeição | VoC |
| Instalações sanitárias | VoC |
| Produtos | VoC |
| Chegada e estacionamento | VoC |
| Alimentação e bebidas | VoC |
| Caixa e pagamento | VoC |
| Máquinas de vending | VoC |
| Espaços infantis | VoC |
| Serviço Pega e Leva | VoC |
| Produtos não alimentares | VoC |
| Serviço Colibri Express | VoC |
| Preço | Só reclamações |
| Reembolsos e faturação | Só reclamações |
| Outros | Sem tema identificado |

## Sentimento

Negativo, neutro ou positivo. No Google vem das estrelas; no Jira é sempre negativo; nas redes sociais vem de regras de palavras-chave.

## Gravidade

| Nível | Critério |
| --- | --- |
| Alta | Risco legal, de segurança ou reputacional (ex.: "DECO", "advogado", "burla", "acidente"), ou review de 1 estrela |
| Média | Queixa concreta sobre o serviço |
| Baixa | Comentário, sugestão ou menção neutra |
