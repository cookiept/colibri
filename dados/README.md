# Dados

**Este repositório é público. Só entram aqui ficheiros fictícios.**

- `exemplos/` tem um ficheiro por fonte com as colunas esperadas e conteúdo inventado. Servem para testar os importadores e para demonstrações.
- Exports reais ficam no computador de cada pessoa e carregam-se na app. O `.gitignore` bloqueia qualquer ficheiro em `dados/` fora de `exemplos/`.
- Se um ficheiro real for enviado por engano, avisar logo: não basta apagá-lo num commit seguinte, porque fica no histórico.
